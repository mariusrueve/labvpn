# Setup files

Double-click a `.labvpn` file with labvpn installed, then enter your login. These files
hold gateway settings only, never usernames or passwords.

| File | For |
|---|---|
| `uni-hamburg.labvpn` | University of Hamburg: UHH and ZBH gateways. The ZBH gateway needs access level 2 or higher, and activation by an admin. UHH asks for browser sign-in at least every 24 hours. |

Only import setup files from people you trust: a gateway can see your traffic.
